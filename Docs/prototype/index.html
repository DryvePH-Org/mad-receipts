How the math works · the rules this page follows
  1. Agreed price is the full price of the unit (all units together).
  2. Trade-in value comes off the price. It is a car, not cash, so it is never part of the balance.
  3. Loan (financing) = price − down payment. The lender pays it to us, so it is not in the balance. If you know the loan instead, the down payment is worked out for you.
  4. Processing fee (financing only, usually 7% of the loan) is owed by the buyer to the lender, not to us. We only collect the down payment, so the fee is shown for information and never changes the balance.
  5. Amount due from the buyer = down payment (or the whole price on a cash sale) − trade-in. Below zero means we pay the buyer.
  6. Balance = amount due − earlier payments − payments today (+ any payout we made to the buyer).
  7. In lieu of documents is collateral: no money moves, so it is never in the math.
  8. Proof: price = trade-in + loan + received − payout + balance. If this does not add up, saving is blocked.
